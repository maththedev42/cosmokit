Scriptable location commands for CLI & AI agents

Automate location testing in CI pipelines and agent loops

Every location tool in CosmoKit is accessible via the free cosmokit CLI and stdio MCP server. AI agents and shell scripts can query scenarios, set coordinates, and run routes programmatically.

  • Run cosmokit location <lat> <lon> to position simulators from scripts
  • Query built-in scenarios with cosmokit scenarios
  • Start dynamic routes with cosmokit route <scenario>
  • Stop simulation cleanly with cosmokit location-clear
# Put the simulator in Rio de Janeiro before running tests
$ cosmokit location -22.9068 -43.1729

# Run built-in freeway drive scenario
$ cosmokit route "Freeway Drive"

# Clear location simulation
$ cosmokit location-clear
