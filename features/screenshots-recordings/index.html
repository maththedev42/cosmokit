Automated captures in CI and scripts

Drive visual regression tests from the cosmokit CLI

Incorporate simulator visual capture into your automated build pipelines and git hooks. The free cosmokit CLI provides scriptable capture and recording commands that output directly to target directories.

  • Run cosmokit capture to save screenshot artifacts in CI jobs
  • Record simulator sessions during integration tests with cosmokit record
  • Target specific booted or named simulators with UDID flags
  • Zero graphical dependencies required for CLI screenshot tasks
# Capture booted simulator into repository screenshots
$ cosmokit capture --output ./screenshots

# Record 10-second interaction video
$ cosmokit record --output ./artifacts/test-run.mp4
